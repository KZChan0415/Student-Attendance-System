# Anti-Proxy Student Attendance System with NFC Integrated Card

## Overview
This final year project is an Anti-Proxy Student Attendance System with NFC Integrated Card built to prevent proxy attendance with multi-factor authentication such as contactless card and facial recognition.

## APIs
- **Web NFC API :** API for NFC card reading.
- **JavaScript Face API :** API for face detection and recognition.

## Features
- **Register Face**
- **Select Class**
- **Select Week**
- **Scan Attendance**
- **View Attendance**

## System Prequisite
Admin is required to register students' facial feature with the register face feature.

## System Instructions
Steps to mark for attendance:

1. Lecturer select class.
2. Lecturer select week.
3. Student tap NFC card behind smartphone and face the camera for template matching.
4. Student and lecturer view attendance to ensure attendance marked.
